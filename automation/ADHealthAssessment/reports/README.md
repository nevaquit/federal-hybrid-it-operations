# Sanitized Sample Reports

This directory contains fictional sample output that demonstrates the reporting format produced by `Invoke-ADHealthAssessment.ps1`.

- `Sample-HealthReport.html` provides an executive-friendly visual report.
- `Sample-HealthReport.json` demonstrates the structured schema for automation and dashboard integration.

The sample domain, hostnames, timestamps, findings, and recommendations are fabricated. Do not commit real production reports without reviewing them for internal hostnames, domains, IP addresses, event data, or other sensitive infrastructure information.
